## 3. Procédure de Contact

### 3.1 Critères de Contact

**Contact Immédiat** :
- Incidents critiques
- Violations données personnelles
- Cybercrimes
- Menaces imminentes

**Contact Rapide (< 24h)** :
- Vulnérabilités critiques
- Intrusions confirmées
- Fuites données

**Contact Standard (< 72h)** :
- Vulnérabilités importantes
- Incidents modérés
- Requêtes autorités

### 3.2 Processus

1. **Évaluation** : Gravité, type incident
2. **Décision** : Contact nécessaire ?
3. **Préparation** : Informations à fournir
4. **Contact** : Via canal approprié
5. **Suivi** : Coordination continue
6. **Documentation** : Log contact

### 3.3 Informations à Fournir

**Minimum** :
- Type incident
- Date/heure
- Impact estimé
- Actions prises
- Coordonnées contact

**Complet** :
- Détails techniques
- Logs pertinents
- Preuves
- Timeline
- Plan récupération
