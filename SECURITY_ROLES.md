## 2. Rôles Détaillés

### 2.1 CISO (Chief Information Security Officer)

**Responsabilités** :
- Définition stratégie sécurité
- Approbation politiques
- Supervision implémentation
- Gestion incidents majeurs
- Conformité réglementaire
- Budget sécurité
- Communication management

**Autorités** :
- Approbation politiques
- Escalade incidents
- Allocation ressources
- Décisions stratégiques

**Compétences Requises** :
- Expertise sécurité
- Leadership
- Communication
- Gestion risques

### 2.2 Security Officer

**Responsabilités** :
- Implémentation contrôles
- Monitoring sécurité quotidien
- Gestion incidents opérationnels
- Review code sécurité
- Formation équipe
- Maintenance outils sécurité
- Reporting sécurité

**Autorités** :
- Accès systèmes sécurité
- Configuration contrôles
- Escalade incidents
- Recommandations améliorations

**Compétences Requises** :
- Expertise technique sécurité
- Analyse risques
- Gestion incidents
- Communication

### 2.3 Security Developer

**Responsabilités** :
- Développement fonctionnalités sécurité

- Tests sécurité

- Support équipe

**Autorités** :
- Accès code sécurité

**Compétences Requises** :
